# 多账号快捷方式（Mac）

## 用法（只用 .app，不会打开终端）

解压后双击 **`多账号快捷方式.app`**。

使用 **系统原生弹窗**（osascript），不会出现黑屏：

1. **搜索**（可留空）：输入关键字筛选，或直接下一步显示全部
2. **选择应用**：列表中带 **[推荐]** 的支持更好隔离（WorkBuddy / Cursor / VS Code / Chrome / Qoder / QoderWork / Grok 等）
3. **账号方案**：默认 account1 + account2
4. **数据位置**：选存放目录
5. **确认创建**：生成桌面与「应用程序」里的 `.app`（无 `.command`，不弹终端）

### 打不开时

1. **右键**「多账号快捷方式.app」→ **打开**
2. 或双击 **`若打不开请先打开我.app`**
3. 或：系统设置 → 隐私与安全性 → **仍要打开**

## 注意

- 包内没有 `.command`，请不要找终端脚本
- WorkBuddy 请先全部退出，再用新快捷方式分别登录
- 界面为 macOS 系统列表/对话框，兼容深色模式
